# B端SaaS功能设计文档 - 能源电力交易平台

## 一、产品概述

### 1.1 产品背景

随着电力市场化改革的深入，越来越多的能源企业、发电集团、售电公司需要一个统一的SaaS平台来管理电力交易业务。传统的本地化部署模式存在以下痛点：

| 痛点 | 说明 |
|------|------|
| **部署成本高** | 每个企业单独部署服务器，硬件+软件成本高 |
| **数据隔离难** | 多企业共用系统时，数据安全和隔离存在挑战 |
| **运维复杂** | 每个企业独立运维，更新迭代效率低 |
| **扩展困难** | 业务增长时难以快速扩容 |
| **成本不透明** | 前期投入大，ROI难以评估 |

为解决以上痛点，我们设计了**多租户SaaS架构**的能源电力交易平台，支持按订阅付费，灵活扩展。

### 1.2 产品目标

| 目标 | 指标 | 说明 |
|------|------|------|
| **租户规模** | 100+企业租户 | 覆盖发电、售电、用户侧等多类型客户 |
| **用户规模** | 1000+活跃用户 | 每个租户平均10+用户 |
| **可用性** | 99.9%+ | 保证平台稳定运行 |
| **数据隔离** | 100%安全 | 租户间数据完全隔离 |
| **成本降低** | 60%+ | 相比传统部署模式 |

### 1.3 用户角色体系

| 角色层级 | 角色名称 | 核心职责 |
|---------|---------|---------|
| **平台层** | 平台管理员 | 租户管理、系统配置、全局监控 |
| **租户层** | 租户管理员 | 用户管理、权限配置、账单管理 |
| **业务层** | 交易主管 | 交易策略审批、团队管理 |
| **业务层** | 交易员 | 电力交易操作、数据查询 |
| **业务层** | 财务人员 | 账单查看、发票管理 |
| **业务层** | 普通用户 | 数据查看、基础操作 |

## 二、核心功能模块设计

### 2.1 租户管理模块

#### 2.1.1 功能概述

管理平台所有企业租户，支持租户创建、配置、禁用/启用、数据隔离等核心功能。

#### 2.1.2 功能细节

| 功能 | 描述 |
|------|------|
| **租户创建** | 支持手动创建和自助注册两种方式 |
| **租户配置** | 配置租户名称、行业类型、规模、联系人等信息 |
| **租户状态** | 正常/试用/禁用/欠费四种状态管理 |
| **数据隔离** | 数据库层面完全隔离（Schema隔离模式） |
| **配额管理** | 配置租户的用户数、场站数、数据存储量等配额 |
| **租户到期** | 到期提醒、续费提醒、过期处理 |
| **租户数据导出** | 支持租户数据全量导出（合规要求） |

#### 2.1.3 租户状态流转

```
创建 → 试用 → 正式（付费） → 禁用
          ↓
        欠费（临时禁用）
```

#### 2.1.4 租户创建流程

```
平台管理员手动创建 / 企业自助注册
  ↓
填写租户基本信息（企业名称、行业、规模）
  ↓
选择订阅套餐（基础版/专业版/企业版）
  ↓
配置初始配额（用户数、场站数、存储量）
  ↓
创建租户管理员账号
  ↓
发送激活邮件
  ↓
租户激活，系统初始化租户数据空间
  ↓
租户管理员登录，开始使用
```

#### 2.1.5 数据隔离方案

| 隔离方案 | 说明 | 适用场景 |
|---------|------|---------|
| **Schema隔离** | 每个租户独立数据库Schema | 中大型租户，数据安全要求高 |
| **行级隔离** | 同一Schema，通过tenant_id区分 | 小型租户，成本敏感 |
| **混合模式** | 大客户Schema隔离，小客户行级隔离 | 灵活平衡成本与安全 |

### 2.2 权限体系模块

#### 2.2.1 RBAC权限模型

采用RBAC（基于角色的访问控制）模型，三级权限体系：

```
用户 → 角色 → 权限
```

#### 2.2.2 权限粒度设计

| 权限层级 | 说明 | 示例 |
|---------|------|------|
| **模块级** | 控制是否可访问某个功能模块 | 交易模块、数据模块、结算模块 |
| **页面级** | 控制是否可访问某个具体页面 | 电价查询页、复盘分析页 |
| **操作级** | 控制是否可执行某个操作 | 新增、编辑、删除、导出、审批 |
| **数据级** | 控制可访问的数据范围 | 本人数据、本部门数据、全部数据 |
| **字段级** | 控制可查看的字段 | 敏感字段（如成本价）隐藏 |

#### 2.2.3 预设角色定义

| 角色 | 模块权限 | 数据范围 | 说明 |
|------|---------|---------|------|
| **租户管理员** | 全部模块 | 全部数据 | 租户最高权限 |
| **交易主管** | 交易+数据+结算 | 全部数据 | 可审批交易策略 |
| **交易员** | 交易+数据 | 本人+部门 | 执行交易操作 |
| **财务人员** | 结算+账单 | 全部数据 | 财务相关操作 |
| **普通用户** | 数据+报表 | 本人数据 | 仅查看权限 |
| **只读用户** | 数据（只读） | 本人数据 | 完全只读 |

#### 2.2.4 自定义角色

支持租户管理员创建自定义角色：

```
选择基础角色模板
  ↓
调整模块权限（勾选/取消）
  ↓
配置数据权限范围
  ↓
设置操作权限（增删改查导出）
  ↓
保存角色
  ↓
分配给用户
```

#### 2.2.5 权限检查流程

```
用户发起请求
  ↓
获取用户角色列表
  ↓
获取角色对应的权限集合
  ↓
检查是否有当前操作权限
  ↓
检查数据范围权限
  ↓
权限通过 → 执行操作
权限拒绝 → 返回403错误
```

#### 2.2.6 权限矩阵示例

| 功能 | 租户管理员 | 交易主管 | 交易员 | 财务 | 普通用户 |
|------|-----------|---------|-------|------|---------|
| 用户管理 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 角色配置 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 交易操作 | ✅ | ✅ | ✅ | ❌ | ❌ |
| 策略审批 | ✅ | ✅ | ❌ | ❌ | ❌ |
| 数据查询 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 数据导出 | ✅ | ✅ | ⚠️ | ✅ | ❌ |
| 账单管理 | ✅ | ❌ | ❌ | ✅ | ❌ |
| 场站管理 | ✅ | ✅ | ❌ | ❌ | ❌ |

> ⚠️ 表示需申请审批后才可执行

## 三、核心业务流程

### 3.1 租户注册与激活流程

```mermaid
flowchart TD
    A[企业自助注册] --> B[填写企业信息]
    B --> C[选择套餐]
    C --> D[支付首月费用]
    D --> E[创建租户管理员账号]
    E --> F[发送激活邮件]
    F --> G[点击激活链接]
    G --> H[设置密码]
    H --> I[系统初始化租户空间]
    I --> J[登录平台]
    J --> K[配置组织架构]
    K --> L[添加用户]
    L --> M[分配角色权限]
    M --> N[正式使用]
```

### 3.2 权限申请与审批流程

```mermaid
flowchart TD
    A[用户发起权限申请] --> B[填写申请理由]
    B --> C[选择需要的权限]
    C --> D[提交申请]
    D --> E[上级审批]
    E --> F{审批结果}
    F -->|通过| G[系统分配权限]
    F -->|拒绝| H[告知原因]
    G --> I[发送通知]
    H --> I
```

### 3.3 账单生成与支付流程

```mermaid
flowchart TD
    A[每月1日 00:00] --> B[系统生成账单]
    B --> C[计算套餐费+超量费+增值费]
    C --> D[发送账单通知]
    D --> E{7天内支付?}
    E -->|是| F[确认到账]
    E -->|否| G[功能限制]
    F --> H[开具发票]
    G --> I{15天内支付?}
    I -->|是| F
    I -->|否| J[账号冻结]
    H --> K[发送发票]
```

## 六、安全设计

### 6.1 数据安全

| 安全措施 | 说明 |
|---------|------|
| **数据加密** | 敏感字段（密码、手机号）加密存储 |
| **传输加密** | HTTPS全程加密传输 |
| **数据备份** | 每日备份，异地存储 |
| **数据隔离** | 租户间数据完全隔离 |
| **脱敏展示** | 敏感数据脱敏显示（如手机号中间4位） |

### 6.2 访问安全

| 安全措施 | 说明 |
|---------|------|
| **登录安全** | 密码强度校验、验证码、登录IP白名单 |
| **会话管理** | Session超时、单点登录、异地登录提醒 |
| **操作审计** | 所有操作留痕，可追溯 |
| **API鉴权** | Token鉴权，接口频率限制 |
| **防暴力破解** | 登录失败次数限制，自动锁定 |

### 6.3 权限安全

| 安全措施 | 说明 |
|---------|------|
| **最小权限原则** | 仅分配必要权限 |
| **权限前置校验** | 前后端双重权限校验 |
| **敏感操作二次确认** | 删除、导出等操作需二次确认 |
| **权限变更审计** | 所有权限变更记录日志 |

## 十、总结

本B端SaaS功能设计文档围绕**能源电力交易平台**场景，构建了完整的多租户SaaS体系：

### 10.1 核心亮点

1. **完善的租户管理** - 支持多租户数据隔离、配额管理、状态控制
2. **灵活的权限体系** - RBAC模型，5级权限粒度，支持自定义角色
3. **清晰的计费模式** - 套餐订阅+超量计费，灵活组合
4. **完整的审计体系** - 全链路操作留痕，可追溯
5. **安全可靠** - 数据加密、权限控制、审计日志三重保障

### 10.2 业务价值

| 价值维度 | 说明 |
|---------|------|
| **降低成本** | 相比传统部署，成本降低60%+ |
| **快速上线** | 租户注册后1天内即可使用 |
| **灵活扩展** | 按需升级套餐，资源弹性扩容 |
| **安全合规** | 数据隔离、审计日志满足合规要求 |
| **持续迭代** | 平台统一升级，客户无需维护 |

### 10.3 技术亮点

- **Schema隔离** - 保证租户数据安全
- **前后端双重校验** - 权限控制更可靠
- **异步处理** - 账单生成等耗时任务异步执行
- **可扩展架构** - 支持1000+租户、10000+用户规模
